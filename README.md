# 🍲 火锅计时器 · 川渝火锅涮煮计时器

轻量级网页应用：涮火锅时给食材计时。纯前端、零依赖、打开即用。

## 功能

- ⏱️ 点一下食材即入列表并自动开计时；支持暂停/继续/加一份/删除
- 🥘 内置 100+ 川渝火锅常见食材（肉类 / 海鲜 / 蔬菜 / 豆制品 / 丸滑 / 其他），每条附参考时长与"熟度提示"
- ⭐ "我的食材"自定义库：任意名称 + 时长
- ⏲️ 快速计时：15 秒 ~ 10 分钟，随手点
- 🔔 到点提醒：提示音 + 震动 + 系统通知（兜底）+ 全屏闪光
- 💾 localStorage 持久化：刷新/重开页面，进行中的计时自动续算
- 📱 移动端优先，为火锅桌旁单手操作优化

## 使用

浏览器直接打开 `index.html` 即可。

## 数据管线

食材数据以 CSV 为唯一事实源：

```
hotpot_food_library (1).csv  --(convert_csv.py)-->  foodDatabase.js
```

**修改食材时只编辑 CSV**，然后重新生成：

```bash
python convert_csv.py
```

> 注意：`foodDatabase.js` 是生成产物，请勿手改。脚本目前硬编码了 CSV 文件名且无 schema 校验，规范化（命名 + 校验 + codegen）在路线图中。
